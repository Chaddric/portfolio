Projects

Three projects, one habit: finishing.

Coursework from the last few years — a marketplace, a game prototype, and a research project. Each one started as an assignment and ended up teaching me something the last one hadn't.

Academic project

UniMart

A campus marketplace web application built for students to buy and sell items within their school community. Users can list products with photos, browse and filter by category, and message each other about an item.

Highlights

  • User registration and authentication
  • Product listings with image uploads
  • Search, category filtering, and sorting
  • Messaging between buyers and sellers
  • Personal dashboard for managing listings

Built with

  • Django
  • Python
  • Tailwind CSS
  • MySQL

Game prototype

Honey, I'm Home

A first-person psychological horror game where the player completes chores, solves puzzles, and looks for a way out of a house while avoiding a dangerous stalker. The PS1-inspired low-poly look keeps the focus on atmosphere and tension rather than detail.

Highlights

  • First-person exploration
  • Task-based gameplay and puzzles
  • Stalker encounters and stealth
  • Retro low-poly 3D environments
  • Atmospheric lighting and sound

Built with

  • Godot
  • GDScript
  • Blender
  • 3D Level Design

Research project

AI-Powered IT Career Assessment

A system concept that helps IT students find likely career paths from their interests, skills, and knowledge — then connects the results to relevant job opportunities. The screen flow maps the whole journey from sign-up and verification to the assessment and matched roles.

Planned features

  • Interactive IT career assessment
  • Personalised career recommendations
  • Skill evaluation with suggested areas to improve
  • Mapping of results to real job openings
  • AI-assisted interpretation of answers

Built with

  • Artificial Intelligence
  • Research
  • UI Design
